## Limitações mantidas

O emulador disponível usa API recente. Compatibilidade mínima declarada é API 26; falta execução manual nessa versão. Doze, reinício, notificação real e condições reais de rede/permissões ainda merecem validação em dispositivo. Os testes dirigidos usam respostas simuladas; abrir o resumo pode executar a sincronização de leitura previamente autorizada pelo usuário. Não há escrita de tarefas no Moodle.

A cobertura Moodle é de trabalhos/assignments e tem limites documentados de consulta. Não se promete atualização instantânea ou sincronização completa de todo tipo de conteúdo. Importações antigas sem referência remota são conservadoras e podem exigir revisão.
